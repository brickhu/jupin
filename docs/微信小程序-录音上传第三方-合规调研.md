# 微信小程序「录音 + 上传音频到第三方服务」合规调研

> 以微信官方文档与政府法规原文为准。【官方】=有官方出处；【推断/二手】=无官方出处。

## 1. 录音授权
- 录音对应 `scope.record`，覆盖 wx.startRecord、RecorderManager.start 等。【官方】[授权](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/authorize.html)
- 流程：未授权过→自动弹窗；已同意→直接调用；**已拒绝→不再弹窗，直接进 fail 回调**，必须兼容。用 wx.getSetting 查状态、wx.openSetting 引导开启、wx.authorize 提前申请；授权保留至用户删除小程序。【官方】[同上](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/authorize.html)
- 拒绝权限后不得自动退出、关闭或停止全部服务；不得在用户不知情时录音。【官方】[运营规范 15.1.3.2 / 12.5.4](https://developers.weixin.qq.com/miniprogram/product/)

## 2. 服务类目资质
- 教育服务门槛高：学历教育（培训机构）需《民办学校办学许可证》+营业执照；非学科类培训机构需《非学科类校外培训机构培训许可证》等 4 选 1；在线视频课程 5 选 1（含视听节目许可证）；教育平台需《增值电信业务经营许可证》+ 2 家以上机构合作协议。【官方】[开放的服务类目](https://developers.weixin.qq.com/miniprogram/product/material/)
- **个人主体教育服务仅有「教育信息展示」，明确不支持教育视频播放/直播与课程销售**，个人号无法承载口语评测产品。【官方】[同上](https://developers.weixin.qq.com/miniprogram/product/material/)
- 无「口语评测/英语学习」专门类目，须按实际形态归入教育服务或工具类目送审。【推断】[类目表未收录](https://developers.weixin.qq.com/miniprogram/product/material/)
- 备案环节校外培训属前置审批，需「教育部门允许开展校外培训的审批文件」（依「双减」意见）；小程序须先完成 ICP 备案（新增小程序 2023-09-04 开放入口）。【官方】[备案操作指引](https://developers.weixin.qq.com/miniprogram/product/record/record_guidelines.html)

## 3. 隐私协议
- 录音的隐私类型为**「访问你的麦克风」**，对应 wx.authorize({scope:'scope.record'}) 等上述接口。【官方】[隐私保护指引内容介绍](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)
- 未在指引中声明即**直接禁用**，报错 errno 112「api scope is not declared in the privacy agreement」。【官方】[隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)
- 强制启用经两次延期，最终为 **2023 年 10 月 17 日**起一律启用（非 9 月）。相关接口：wx.getPrivacySetting、wx.onNeedPrivacyAuthorization、wx.requirePrivacyAuthorize（模拟隐私接口调用）、`<button open-type="agreePrivacyAuthorization">`；基础库 <2.32.3 不拦截。【官方】[同上](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)

## 4. 网络请求与域名白名单
- wx.request / wx.uploadFile / wx.downloadFile / wx.connectSocket **只能与已配置域名通信**；仅 https（wss）；禁用 IP 与 localhost；**必须 ICP 备案**；只能配子域名；api.weixin.qq.com 不可配置。【官方】[网络](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)
- 并发上限：三类请求各 10 个、socket 5 个；默认超时 60s；切后台 5s 未结束报 fail interrupted。【官方】[同上](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)
- 数量与修改次数：官方文档**未给出小程序后台直接配置服务器域名的数量上限与每月修改次数**；第三方平台接口写「最多添加 1000 个服务器域名」「每月只可修改 50 次」（错误码 65316 / 45104）；业务域名每账号最多 300 个。**网传「每月 5 次」未找到官方来源**。【官方】[第三方平台服务器域名](https://developers.weixin.qq.com/doc/oplatform/Third-party_Platforms/2.0/api/ThirdParty/domain/modify_server_domain.html)、[业务域名](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/domain.html)
- 结论：**不能直连任意第三方域名**，音频经 wx.uploadFile 上传同样受白名单约束，须加白名单（域名须已备案）或自建后端中转。【官方】[网络](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)

## 5. 出境、未成年人、内容审核
- 未经用户明确同意并披露用途范围，不得复制/存储/传输用户数据；**未经许可不得将收集的用户数据向任何第三方泄漏、提供、披露或许可获取**。【官方】[运营规范 15.2.4 / 15.3.2 / 15.3.4](https://developers.weixin.qq.com/miniprogram/product/)
- 涉及**声纹识别等生物识别技术**，应使用微信平台提供或平台认可的技术功能。【官方】[运营规范 15.3.10](https://developers.weixin.qq.com/miniprogram/product/)
- 《个人信息保护法》第 28 条：生物识别、不满十四周岁未成年人信息属**敏感个人信息**；第 29 条需**单独同意**；第 31 条需监护人同意并制定专门规则；第三章为跨境提供规则。【官方】[网信办 PIPL 全文](http://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)
- 音频送境外引擎须履行《个人信息出境标准合同办法》等义务；《未成年人网络保护条例》自 2024-01-01 施行。【官方】[标准合同办法](http://www.cac.gov.cn/2023-02/24/c_1678884830036813.htm)、[gov.cn](https://www.gov.cn/zhengce/content/202310/content_6911288.htm)
- 内容安全接口 msg_sec_check（文本）、media_check_async（异步校验图片/音频）可用；微信**未**发布「录音必须逐条送审」明文要求。【官方】[内容安全接口](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/sec-center/sec-check/mediaCheckAsync.html) /【未找到官方来源】

## 6. 云开发 / 云托管
- 官方明确：**用微信云托管作后端可无需配置通讯域名**，小程序内经 wx.cloud.callContainer / connectContainer 走微信私有协议（需基础库 ≥2.23.0，且仅限被该环境授权的小程序）。【官方】[网络](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[调用云托管服务](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloudrun/src/development/call/)
- 云托管限制：请求 100KiB（二进制 20MiB）、返回 1000KiB、超时 60s；默认公网域名仅供测试，不得用于生产。【官方】[同上](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloudrun/src/development/call/)
- 「云函数可请求任意第三方域名、不受白名单限制」**未找到官方直接声明**，只能推断（云函数在服务端运行，白名单是小程序端 SDK 限制）。【推断】[云函数文档未提及](https://developers.weixin.qq.com/miniprogram/dev/wxcloud/guide/functions.html)

## 【对小程序选型的影响】
1. **主体须为企业/组织**：个人主体教育类目只有「教育信息展示」，无法承载授课与课程销售；企业主体还需跨过办学许可证等资质门槛。
2. **不能直连第三方评测引擎**：目标域名须 ICP 备案 + HTTPS 且加入白名单，名额与修改次数受限。优先选域名长期稳定的供应商，把域名变更视为迁移成本。
3. **优先自建中转或直接用云托管**：可隐藏引擎 API Key（官方要求 AppSecret 只放服务器）、便于换供应商、解耦备案与白名单；云托管免配通讯域名，但注意 100KiB 请求 / 60s 超时对音频分片上传的影响。
4. **隐私合规是硬门槛**：录音必须在《用户隐私保护指引》声明为「访问你的麦克风」，否则接口直接禁用（errno 112）；2023-10-17 后全量强制。
5. **慎做声纹类评测**：声纹属平台限定须用其认可技术的生物识别场景，且 PIPL 下为敏感个人信息需单独同意；建议初期排除声纹比对，并优先境内引擎以规避出境合规成本。
