# 打分标准（校准后）

> 目的：**这个分要给用户当荣誉，必须权威。**权威 = 可复现 + 可解释 + **有参照系**。
> 这份文档给的是参照系和由它推出的权重 —— 不是拍的。

## 一、行业的标准是什么样（有出处）

| 体系 | 维度 | 权重 |
|---|---|---|
| **雅思口语**（人评） | 流利与连贯 / 词汇 / 语法 / **发音** | **各 25%**；发音里明确要求「重音、连读、语调变化，避免平铺直叙」 |
| **Azure 发音评估**（技术方案） | Accuracy（音素→音节→词→全文逐级汇总）/ Fluency（词间静默用得对不对）/ Completeness（读了多少词）/ **Prosody（重音、语调、语速、节奏）** | 四维加权；缺哪项不算哪项。⭐ 另有硬判据：**词级 < 60 即判 Mispronunciation** |
| **讯飞 ISE**（我们在用的） | accuracy / fluency / standard / integrity | `(0.6×acc + 0.3×flu + 0.1×std) × integrity` |

**对比出来的关键差异**：行业把「韵律/语调」当**一等公民**（雅思 25%、Azure 单列 Prosody），
讯飞只给它 **0.1**。而下面实测证明：**它恰恰是最能区分好坏的那一维。**

## 二、校准实验（实测）

**方法**：同一句 `The best way to predict the future is to invent it.`

- 上锚点：macOS 母语级 TTS 两个声音（Samantha / Alex）
- 学习者：本地 `.uploads` 里 10 段真实录音（去重后），其中 2 段因音频过短被判无效（全 0 分，符合预期）

### 结果（只统计 8 段有效学习者样本）

| 维度 | 母语级 | 学习者均值 | **差距** | 学习者范围 |
|---|---|---|---|---|
| 总分（讯飞口径） | 100 | 70.1 | 29.9 | 35.7 ~ 91.6 |
| accuracy | 100 | 73.9 | 26.1 | 39.4 ~ 91.3 |
| fluency | 100 | 78.2 | 21.8 | 66.1 ~ 96.0 |
| **standard** | 100 | **51.6** | **48.4** ⭐ 最强 | 12.2 ~ 89.6 |
| integrity | 100 | 97.9 | **2.1** 最弱 | 91.7 ~ 100 |
| 词均 | 96.4 | 80.9 | 15.5 | 67.0 ~ 89.2 |
| **词最低** | 87.6 | **43.3** | **44.3** ⭐ | 0.0 ~ 71.0 |
| 绿词比（≥85） | 1.00 | 0.50 | 0.50 | 0.2 ~ 0.7 |
| 音节错率 | 0.03 | 0.30 | — | 0.1 ~ 0.5 |
| 音素 gwpp < -4 的个数 | 0.5 | 5.6 | — | 2 ~ 11 |

### 三条结论

1. ⭐⭐ **`standard`（韵律/标准度）是最强区分器（差距 48.4），讯飞却只给它 0.1 权重** ——
   这是「分数不准、拉不开差距」的头号原因。行业（雅思/Azure）把它当一等公民，是对的。
2. ⭐ **`integrity` 对能读完的人几乎是常数（差距只有 2.1）** —— 它不该占正权重，
   只该当**门槛**（有漏读就罚、就封顶）。
3. ⭐ **词级里「最差的那个词」（差距 44.3）比「平均值」（15.5）有用得多** ——
   人耳判断「说得好不好」靠的是**最差的那几个词**，不是平均。

## 三、由此定出的权重（提案）

```
韵律标准 35%   ISE standard + 自算音高起伏（pitch）
发音短板 30%   绿词比(≥85) + 最差词（词级，抓「最差的那几个」）
发音准确 15%   ISE accuracy + 音节检错率（serr_msg）
流利    15%   ISE fluency + 自算停顿/语速
完整    5%    ISE integrity（另设门槛：有漏读 ⇒ 封顶 79）
```

与讯飞口径的对照：`standard` 0.1 → **0.35**（↑3.5 倍）、`fluency` 0.3 → 0.15、
`accuracy` 0.6 → 词级 30% + 准确 15%（拆开，因为「平均」和「短板」是两件事）、
`integrity` 从乘性因子 → 只做门槛。

## 四、分档的参照系（实测支撑）

| 分档 | 含义 | 依据 |
|---|---|---|
| 90–100 | 接近母语者 | 实测：母语级 TTS 满分；学习者 8 段里只有 1 段到 91.6 |
| 80–89 | 流利自然，偶有音不准 | 学习者里最好的那两段 |
| 70–79 | 听得懂，语调平 | 中位区 |
| 60–69 | 能听懂，错误明显 | |
| < 60 | 听不清楚 / 读错太多 | 实测最低 35.7（acc 39、std 14） |

⚠️ 样本量还小（8 段有效、同一个人、同一句）。**权重方向可信（差距排序很清楚），具体数值要再攒人再微调。**
