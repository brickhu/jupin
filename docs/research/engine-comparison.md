# 评分引擎横评

> 调研时间：本轮设计期间。**所有价格与能力均来自官方文档。**

## 一、结论

| 场景 | 选择 |
|---|---|
| **当前（验证期 → 上线）** | ⭐ **科大讯飞 ISE** — 最便宜 + 10 万次免费 + 已踩完坑 |
| 备选（若实时成为刚需） | 驰声 Chivox — 唯一明确支持实时流式 |
| 不选 | 腾讯云 SOE — 增值能力我们不需要，且按长度计费、免费额度少 10 倍 |

**判据**：按设计原则「云端只买一个分数」，引擎的增值能力（实时中间结果、音素对比、IPA、SDK 工程）**要么端侧自建、要么不需要**。剩下的只有「谁打分便宜稳定」。

### ⚠️ 一个曾经的误判（已修正）

早前曾把腾讯云 SDK 的「静音检测 / 流式分片 / 重试」当作**选型优势**。

**这是错的**——那些是**客户端工程实现**，本该端侧自建，不构成引擎能力差异。把工程实现当成产品特性来比，会得出错误结论。

**正确的划分：**

| 类别 | 归属 | 是否构成选型依据 |
|---|---|---|
| 静音检测 / VAD / 能量 / 分片 / 重试 / 签名 | **端侧工程** | ❌ 与选谁无关 |
| **实时中间结果 / 音素对比 / IPA / 评分** | **引擎能力** | ✅ 是 |

## 五、开源方案（真实可走）

| 资源 | 内容 |
|---|---|
| ⭐ **speechocean762** | 5000 条非母语英语录音，**人工标注到音素级**（phones + phones-accuracy + mispronunciations）。HuggingFace 一行代码加载 |
| ⭐ **Kaldi egs/gop_speechocean762** | **Kaldi 官方 baseline recipe** |
| ⭐ **GOPT**（YuanGongND/gopt） | ICASSP 2022 官方实现，PyTorch，**带预训练模型**，多维度 × 多粒度 |
| 其他 | GoParrot、Goodness-of-Pronunciation |

**GOPT 在 SpeechOcean762 上的指标（当前 SOTA）**：音素级 PCC 0.612 · 词级 PCC 0.549 · **句级 PCC 0.742**

### ⚠️ 但开源的价值不是省钱

| 方案 | 月成本（37,500 次） |
|---|---|
| 讯飞 ISE | **¥145** |
| **服务端自建（GOPT）** | **¥200–500**（服务器 + 运维） |

**服务端自建反而比云 API 贵**——单价已经很低，而你要付服务器、运维、可用性成本。

**开源真正的价值有两个：**

1. **端侧推理** —— 边际成本真为 0（但需小模型，GOPT 太大，要 Kaldi TDNN 类）
2. ⭐ **当「尺子的尺子」** —— 用 speechocean762 客观横评各商业引擎

### ⭐ 推荐的用法：用开源数据集做引擎横评

```
speechocean762（5000 条带人工音素级标注）
   ↓ 逐条送进各引擎
讯飞 / 腾讯 / 驰声 / 云知声
   ↓ 对比引擎分 vs 人工标注
得到客观对比表：谁在中国口音上最准 · 谁音素定位最准 · 谁分数分布最合理
```

**成本约 ¥25**（5000 条 × ¥0.005），同时可回答「阈值该定在哪」。
