# 句拼 · 产品定义

## 核心价值主张

1. **解决"不敢开口"：** 短句起步（5-50 词），无需社交压力，独自对着手机朗读即可
2. **60→90 的成长可视化：** 展示"真实进步"——能力分曲线从 60 分到 90 分的全过程
3. **低成本高质量内容：** AI 按难度分级生成，单篇成本 ¥0.0007，零版权风险
4. **信息差即付费动力：** 免费用户只看到两个数字，一切纠正细节都是付费专属
5. **轻学习场景：** 2-5 分钟完成"读→评分→纠音"闭环

## 用户体验闭环

```
用户进入 App
  → 看到今日推荐短文（AI 生成，按能力分推荐难度）
  → 朗读录音 → AI 语音评分（质量分 Q = 四维度简单平均）
  → 获得结果：经验分 E（投入度，只增不减）+ 能力分 P（真实水平，双向浮动）
  → 免费用户：只看到两个数字
  → 付费用户：逐句纠音 + 音素级错误标注 + 三条曲线详情
  → 持续使用 → 能力分曲线上升 → 分享进步卡片 → 带来新用户
```

## 变现模型

| 层级 | 定价 | 核心权益 |
|------|------|---------|
| **免费** | ¥0 | 每日 5 次 AI 评分 + 基础评分 + 经验等级 |
| **单篇解锁** | ¥0.99/篇 | 单篇逐句纠音 + 音素级反馈（解锁当日不占免费额度） |
| **Pro 月付** | ¥29/月 | 每日 500 次评分 + 完整三条曲线 + 所有称号 |
| **Pro 年付** | ¥199/年 | 全部 + 年度发音报告 |

**关键设计：** 单次付费降低决策门槛 → 体验纠音价值 → 自然过渡到订阅。

## 付费墙规则

- **免费用户：** 只看到"经验等级"和"能力分：XX"两个数字，句中无任何单词高亮、错误标注或发音建议
- **付费用户：** 完整的"能力分曲线 / 质量分散点 / 经验分累计"三条曲线 + 单词级/音素级纠错 + AI 发音建议

## 内容策略

- **首发切入点：** 励志名言 / 名人语录（50-200 词，公共领域，零版权风险）
- **内容来源：** DeepSeek V4-Flash 按 CEFR 分级生成，国内 API 直连
- **扩展路径：** 励志名言 → 职场英语 → TED 演讲节选 → 经典文学 → 用户 UGC
- **更新频率：** 每日 3-5 篇新内容，每周策划一个热门话题系列

## 产品原则

1. **能力分曲线是灵魂**——所有产品决策以"这条曲线是否更清晰"为准
2. **先收钱再做大**——从第一天起就收钱，免费用户设计目标是"引导付费"
3. **不做全品类**——只做"朗读评分"这一件事，做到极致
4. **内容质量 > 内容数量**——宁可每天 3 篇好内容，不要 30 篇垃圾
5. **数据驱动迭代**——留存率、付费转化率、能力分提升幅度是三个核心指标

## 冷启动阶段不做

- ❌ 公共社区 / feed 流
- ❌ 多语言 UI（前期只做中文+英文）
- ❌ K12 教培市场
- ❌ 大范围广告投放
- ❌ 自研语音引擎（先用 Azure Speech API）
- ❌ 过于复杂的游戏化系统（经验分+能力分两条线就够）
