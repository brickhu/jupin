# 句说 · 增长与运营

## 获取前 1000 用户（零成本冷启动）

| 渠道 | 方式 | 优先级 |
|------|------|--------|
| **小红书** | 每天 1 条"朗读评分打卡"笔记，展示评分卡 | P0 |
| **英语学习群** | 进群送免费发音诊断（读一句名言，AI 出报告） | P0 |
| **抖音** | 录屏：同一句反复打磨，分数从 60→90 的过程 | P1 |
| **知乎/公众号** | 2-3 篇 SEO 长文（如"每天读 5 分钟英文的变化"） | P1 |
| **微信裂变** | 分享进步卡片得 3 次免费纠音 | P1 |

**目标：** 3 个月 1000 用户 + 盈亏平衡（约需 30-40 付费用户）。

## 关键风险与对策

| 风险 | 对策 |
|------|------|
| 语音 API 成本被低估 | 免费用户每日限 5 次、付费用户每日限 500 次；缓存评分结果；超限引导付费 |
| 朗读场景频次受限 | 接受"每天一次"的频次，深耕单次体验深度 |
| Duolingo 覆盖本功能 | 差异化在"能力分曲线"+"专注短句朗读"，不做全品类 |
| 冷启动社交空城计 | 先用 AI 模拟反馈 + 只做好友PK不做公共广场 |
| 用户留存不足 | 能力分曲线本身就是留存引擎——"我不想断掉进步记录" |
| 中国用户付费意愿低 | 单篇 ¥1 解锁降低决策门槛；定价 ¥29/月处于"奶茶价格带" |
| 抖音/B站等泛内容平台分流 | 不做娱乐化，强调"有效练习"的工具属性 |

## 上线后第一周观测指标

| 指标 | 健康值 | 预警值 | 行动 |
|------|-------|-------|------|
| 次日留存 | > 35% | < 20% | 检查首次体验 |
| 免费→¥0.99 转化率 | > 8% | < 3% | 检查纠音感知价值 |
| ¥0.99→¥29 转化率 | > 15% | < 5% | 检查纠音效果 |
| 录音成功率 | > 90% | < 80% | 检查浏览器兼容性 |
| 完成朗读率 | > 70% | < 50% | 检查录音流程 |
| 分享率 | > 5% | < 1% | 检查分享页吸引力 |
| API 响应时间 | < 3 秒 | > 5 秒 | 优化性能 |
| 7 日能力分变化 | 平均 +3 以上 | 平均 +1 以下 | 检查评分有效性 |

## MVP 核心验证目标

> **MVP 要证明的不是"句说能赚钱"，而是"用户愿意为 AI 纠音这件事付费"。**
> 前者需要规模，后者只需要 100 个人。

上线后反复问三个问题：
1. **用户第二天回来了吗？**（留存）
2. **用户愿意为纠音付钱吗？**（付费转化）
3. **用户的能力分真的在涨吗？**（有效学习）
